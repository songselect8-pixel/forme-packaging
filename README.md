# FORME 礼盒包装网站

已制作一套英文外贸展示网站，暖象牙白 / 墨绿 / 香槟色，包含 15 个静态页面：主页、产品目录、6 个产品详情、定制工艺、品牌介绍、包装指南目录、3 篇指南、联系询价。

## 预览

在本目录运行 `npm start`，打开 http://127.0.0.1:4173 。只需 Node.js，没有需要安装的项目依赖。也可将 `dist/` 直接部署到静态服务器。

## 替换公司信息

编辑 `dist/site-config.js` 顶部 `site`：

- `brand`：品牌简称；`company`：公司英文名称。
- `email`、`phone`、`whatsapp`、`address`：实际联系信息，未提供时为 null。
- `origin`：正式网站网址，用于分享信息和 sitemap。

随后运行 `npm run build`。所有 15 页的品牌、联系方式和元数据会统一更新。产品和指南内容也在这一文件中。更换品牌名称时，原图中的 FORME 字样需要同步重新生成。

## 询价行为

联系方式占位期间，表单只生成可下载的 TXT 项目需求单，不向任何服务器发送个人信息。页面明确说明未发送。用户主动点击“保存草稿”后才将内容保存在当前浏览器，可随时清除。配置 email 后会提供“打开邮件草稿”按钮，邮件由访客自行确认发送。

自动收集询盘到公司邮箱或后台需另外接入真实服务，目前没有假装提交成功的接口。

## 图片与视频

7 张产品照片均在本次任务中重新生成。WebP 图片在 `dist/assets/`，原始 PNG 保存在本地 `output/originals/` 以及 Codex 图片生成目录。未下载或使用参考站的任何图片、视频或标识。图片用于设计展示，最终产品尺寸、材质和生产信息需按实际业务确认。

`dist/assets/forme-film.mp4` 是使用原创生成图制作的 12 秒无声动态画册（1280×720 / H.264），附英文描述字幕。它不是工厂实拍或真实开箱录像。`prepare-media.py` 可使用 Python 标准库和已安装的 FFmpeg 重建图片与视频；其中生成原图路径是本机路径。

字体是本地托管的 Cormorant Garamond 和 Manrope，来自 Google Fonts，许可证随附。

## 验证与维护

`npm run build` 重新生成静态页面；`npm test` 检查分类筛选、需求单内容和全部页面的内部链接、图片与锚点。实际浏览器已检查桌面与手机排版、手机菜单、产品过滤、产品详情到询价预填、表单验证、草稿保存与清除、需求单下载、FAQ 和视频播放。

正式使用前补充：公司名称与 Logo、实际邮箱/电话/WhatsApp/地址、真实公司背景和产品参数。网站不包含编造的客户评价、工厂产能、认证、MOQ 或交期。
