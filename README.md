# FORME 礼盒包装网站 · 按参考站结构重做

参考：https://luxopack.com/ 。本版根据用户纠正，保留参考站的内容层级、导航、首页模块顺序和产品陈列密度，替换配色、字体、全部图片与视频，并改写文案。第一版画册式网站已被本版替代，之前的页面链接仍可跳转到新版。

## 页面与栏目

131 个完整静态页面，另保留 14 个旧链接跳转页。首页完整展示 78 个产品条目，每款均可进入独立详情页。导航沿用 Products / Industries / Cases / Certifications / Blog / About / Get Quote；行业页包含 18 个分类。

新增彩印系列已接入首页、产品导航、页脚、目录筛选、系列页、产品详情、行业推荐、资源指南和询价选项。文章页改用紧凑配图、目录和独立阅读栏。

首页保留视频首屏、展示视频、数据栏、公司概况、MOQ/价格表、行业分类墙、78 款产品、六种工艺、两栏对比、开箱展示、优势、认证、四步流程、知识问答、评价、产品 FAQ、博客、简版 FAQ、询价和资源模块。

公司历史、产能、认证、客户评价和联系方式留有明确占位。价格计算器使用清楚标注的示例规划数据，最终价格和 MOQ 按实际项目确认。

## 本地预览与生成

只需 Node.js，无项目依赖安装：

```
npm run build
npm test
npm start
```

本地预览：http://127.0.0.1:4173/ 。`dist/` 可直接部署到支持目录索引的静态服务器。`serve.mjs` 支持嵌套目录与视频 Range 请求。

## 替换信息

`dist/site-config.js`：品牌、公司名、邮箱、电话、WhatsApp、地址和正式网址；估价器的示例系数也在该文件。

`dist/catalog-data.js`：78 款产品的名称、图片、规格字段、分类与详情地址。

`dist/series-data.js`：三类彩印系列的结构、材料、检查要点和指南关联。

`content/articles.mjs`：14 篇独立主题文章，含段落、比较表、清单与相关链接；文章首图桌面 320×212 像素，手机最高 205 像素。

`build.mjs`：首页和其他页面的模块文案，公司背景、资质、数据与评价位置。修改后运行 `npm run build`。

品牌暂用 FORME。更换品牌时，带 FORME 字样的产品图片也需同步重新生成。

## 原创素材

78 张逐款匹配的原创产品图，本轮全部重新生成，统一暖白棚拍风格，核对盖底、抽屉、插舌、摇盖、折角及内托关系。三类新增彩印系列各含 6 款应用产品。网页使用优化 WebP，选定的原始 PNG 在本机 `output/structure-originals/`；提示词在 `docs/product-image-prompts.json`，结构参考与复核说明在 `docs/image-structure-audit.md`。

12 秒 H.264 产品展示短片已同步换成磁吸礼盒、彩印运输箱、瓦楞飞机盒和白卡盒的新图制作，不是工厂实拍。公司实际生产影像可替换对应视频位置。网站没有使用参考站的照片、视频、Logo、联系人或追踪代码。

字体 Manrope 本地托管，许可证在 `licenses/`。

## 表单与估价

报价页包含盒型、数量和工艺规划计算器，并能将选择写入询价表单。表单支持产品预填、附件选择与 10 MB 大小校验、NDA 需求、必填校验、主动保存草稿、清除草稿和 TXT 需求单下载。

真实联系渠道未接入前，表单不会发送信息或文件。网页明确提示未发送。配置邮箱后可打开由访客确认发送的邮件草稿。附件只在本地选择，下载的需求单记录附件文件名。
